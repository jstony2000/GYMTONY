Sincronización GitHub (Nube)

Sin configurar

Guarda automáticamente tus entrenamientos, ejercicios nuevos y GIFs en tu repositorio para tener lo mismo en móvil y PC.

1. Crear Token en GitHub ↗
Pasos exactos en GitHub:
1. Pulsa Crear Token en GitHub ↗ arriba (inicia sesión si te lo pide).
2. Token name: escribe GymTony.
3. Expiration: elige Custom (máximo 1 año) para no renovarlo cada mes.
4. Repository access: marca Only select repositories y elige GYMTONY.
5. Permissions → Repository permissions: busca Contents y cámbialo de No access a Read and write.
6. Baja del todo, pulsa Generate token (botón verde) y copia el código (github_pat_...).
7. Vuelve aquí y pulsa 2. Pegar y Probar abajo.
